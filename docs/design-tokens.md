# 红楼宇宙 · 设计 Token 规范 V1

> 风格定位：新中式 · 雅致人文（参考图提取 + 产品"淡雅东方文学感"原则）
> 原则：低饱和、重留白、宋体标题、一切装饰克制，服务于"知识资产"而非"视觉炫技"。

---

## 1. 色彩 Color

### 1.1 语义色板

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#F9F5F0` | 页面主背景（宣纸米白，非纯白） |
| `--bg-alt` | `#F2EDE4` | 分区背景 / Hero 底 |
| `--surface` | `#FFFFFF` | 卡片背景 |

| `--primary` | `#A63834` | 朱砂红：主按钮 / 高亮 / 徽章 / 时间线节点 |
| `--primary-strong` | `#8A2C28` | 朱砂深红：hover / active |
| `--gold` | `#C49A6C` | 古铜金：图标描边 / 分隔线 / 印章描边 |
| `--btn-secondary` | `#E8D9C9` | 次要按钮底色 |
| `--btn-secondary-text` | `#5C4A3D` | 次要按钮文字 |
| `--text-title` | `#2C2C2C` | 标题（比纯黑柔和） |
| `--text-body` | `#595959` | 正文 |
| `--text-muted` | `#8C8C8C` | 辅助 / 次要信息 |
| `--border` | `#D4C7B9` | 卡片外描边（双线外线） |

| `--seal-red` | `#C0392B` | 印章红（装饰，低透明度叠加） |

### 1.2 使用规则

- 强调色只用于：主 CTA、选中态、时间线节点、身份徽章、关键高亮文字。**正文不出现朱砂红。**
- 背景永不使用纯白 `#FFFFFF` 作为页面底色。
- 装饰色（金/印章红/水墨灰）只做点缀，单屏占比 < 5%。

---

## 4. 间距与栅格

- 基准单位 `4px`，使用 8 的倍数：`8 / 16 / 24 / 32 / 48 / 64`。
- 页面内容区最大宽度 `1200px`，左右留白 `24px`。
- 卡片间距 `16-24px`；板块间距 `48px`；**Hero 以下必须有呼吸感，宁空勿满。**

---

## 5. 装饰元素（克制使用）

| 元素 | 规范 |
|---|---|
| 宣纸纹理 | 页面底色叠加纹理，透明度 `~8%`，SVG 噪点或 CSS 渐变 |
| 双线描边 | 卡片边框：`1px solid var(--border)` 外套 `1px solid var(--border-inner)` 内线 |
| 印章 | 尺寸 `24px`，朱文篆刻风格，正红 `#C0392B`，整体透明度 `70-90%`，用于 Logo、CTA 角标、章节标题 |
| 祥云 | 分隔线 / 页脚 / 弹窗顶部，矢量 SVG，渐变 `#F5E6D3 → #FFF9F0` |
| 水墨插画 | Hero 与章节封面，远山叠嶂 / 亭台楼阁 / 大观园意境；人物头像用工笔画风 |
| 暗纹 | 梅 / 竹剪影背景点缀，透明度 `15-20%`，仅限卡片角落 |

## 6. 关键组件速查

| 组件 | 规范 |
|---|---|
| 导航栏 | 高 `64px`，sticky；激活项下细红线 `2px #A63834` 居中，hover 红线由中心展开 0.3s |
| 主按钮 | 胶囊形，朱砂红渐变 `#A73D3D → #8B2E2E`，白字 16px/700，hover 上浮 2px，点击内缩 |
| 次要按钮 | 圆角 6px，`#E8D9C9` 底 + `#5C4A3D` 字，hover 变 `#F5EBE0` |
| 人物卡片 | 圆头像 80px + 宋体姓名，hover 头像放大至 90px 出"查看详情"浮层 |
| 时间线 | 垂直轴虚线 `#A89F91`，节点朱砂红圆点 + 微型印章；事件卡内含图标 + 参与人物缩略头像 |
| 诗词卡 | 横条卡：左诗句（宋体 16px/行高 2.0，`#3E2723`），右插图；出处右对齐小字 |
| 标签徽章 | 高 20px 圆角 4px；热门红 `#D9534F` / 最新蓝 `#5BC0DE` / 精华金 `#F0AD4E` / 身份章：主角金边红底、配角银边蓝底 |
| 引用卡（证据） | 暖白底 `--surface-warm` + 金线描边，内含回数 + 原文 + 出处来源名，点击跳转章节 |

---

## 7. 动效

- 所有动效 ≤ 0.3s，缓动 `cubic-bezier(0.25, 0.1, 0.25, 1)`。
- 允许：淡入淡出、轻微上浮（2-4px）、红线展开、花瓣/水波微动画（Hero 限定，10% 以下透明度）。
- 禁止：弹跳、旋转入场、流光扫过等炫技效果。
