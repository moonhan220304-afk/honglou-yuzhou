## 1. 文本事实与版本边界

### 1.1 前 80 回（曹雪芹）——本卡唯一的事实依据

| 回目 | 事实（构图与气质的关键锚点） |
|---|---|
| 第 1 回 | 甄士隐独女甄英莲，三岁元宵被拐；僧道谶语「有命无运」「菱花空对雪澌澌」 |
| 第 4 回 | 十二三岁被拐子出卖；葫芦案，冯渊（逢冤）被薛蟠豪奴打死，英莲被强夺入薛家，宝钗为她取名**香菱** |
| 第 7 回 | 周瑞家的送宫花：问身世，香菱皆答「**不记得了**」；金钏儿：「倒好个模样儿，竟有些像咱们东府里蓉大奶奶的品格儿」 |
| 第 16 回 | 薛姨妈摆酒请客，明公正道收房，香菱为薛蟠之妾 |
| 第 48 回 | **香菱学诗**（本图构图主题）：随宝钗住大观园，拜黛玉为师，「茶饭无心，坐卧不定」，苦吟三易其稿，梦中得句「精华欲掩料应难」 |
| 第 62 回 | 回目「呆香菱情解石榴裙」——斗草「夫妻蕙」、弄脏石榴裙、宝玉换裙 |
| 第 79 回 | 薛蟠娶夏金桂，香菱痴心「又添一个作诗的人了」 |
| 第 80 回 | 被改名**秋菱**，自此「酿成干血之症」 |

判词（第五回）：**「根并荷花一茎香，平生遭际实堪伤。自从两地生孤木，致使香魂返故乡」**——「两地生孤木」合为「桂」字，指死于夏金桂之手。「菱花／水菱」意象是本图背景元素（浅水菱叶）的来源。

## 2. 视觉核心设定

### 2.1 年龄
- 本图取 **约十五六岁** 的少女（据第 4 回「十二三岁」锚点 + 知识库「比宝钗略小」推算；前 80 回末约 19–20 岁，不取）。
- 定位：**稚气少女**——比宝钗小、比丫鬟们同龄，既非孩童也非少妇。

### 2.2 身份
- 薛蟠之妾、随宝钗入园的学诗者（第 48 回语境）。
- 着装为**素雅家常衣裙**：不穿主子贵妇装束、不穿嫁娶/宴乐盛装；与钗黛的闺秀常服相类但更简素，一眼可辨「非小姐」。

### 2.3 气质（原文依据 + 视觉转化）
- 原文定评：温柔秀美、眉目娇柔、神情**痴纯**（V2 清单）；「呆香菱」之呆（第 62 回回目）；天真到「不记得」自己身世。
- 视觉转化：目光专注而纯真，微微含痴（读诗入神），带一丝怯生生的温柔；**淡而有生气**——气色温润健康，绝不病弱、绝不愁苦含怨。

### 2.4 姿态（本图唯一姿势）
- 半身、居中；上身**微微前倾**，双手**捧诗稿**（或轻持稿微读），目光落于稿上，神情痴迷专注。
- 诗稿只作道具，**不遮挡脸部**；无其他人物、无第二个手部动作。

### 2.5 服饰与发饰
- 衣裙：**浅杏色（杏白/杏黄调）或淡藕色（淡藕荷）**主色，素面无重绣，质地柔和。
- 发饰：**简约**——单支素色细簪或细发带，可配一朵小菱花；**无金饰、无珠翠、无凤钗步摇**。
- 排除：石榴裙（大红，第 62 回元素，本图不用）。

## 3. 与 V1 四张锚点的明确区分（防复用脸）

> 硬性要求：**不得复用或变造黛玉、宝钗、晴雯、可卿中任何一张的脸与五官排布**；香菱是一张全新人脸，气质向「稚气、圆润、痴纯」偏移。

| 锚点 | V1 既有形象特征 | 香菱必须的差异化 |
|---|---|---|
| 林黛玉 | 清瘦病弱、眉目含愁、气韵清冽孤峭（潇湘馆竹影意象） | 脸**略圆**、有婴儿感；气色温润健康，**淡而不病弱**；不落泪含愁，而是痴迷专注 |
| 薛宝钗 | 端凝雍容的**闺阁贵女**，脸圆而丰、仪态大气体面（有金玉华贵气） | 不是贵女——素净简淡、无重金发饰，身份卑微的妾室气度；神情天真而非周全体面 |
| 晴雯 | 削肩蜂腰、眉眼**伶俐锋利**、姿容明艳灵动 | 眉眼娇柔痴纯、无锋锐感；姿态安静读书而非泼辣活泼 |
| 秦可卿 | **浓艳少妇**、袅娜纤巧、鲜艳妩媚、风流贵妇气 | 稚气少女、非少妇；淡妆素衣，**不是浓艳**；可卿是「品格」相近的镜像而非形象复用（第 7 回「像蓉大奶奶的品格儿」只取其温柔秀美，不取其妩媚浓艳） |

共性底线：全新圆润少女脸（脸颊微圆、下颌线条柔和）、淡扫蛾眉、无重金发饰、神情痴纯——与四张锚点任何一张并排即能区分。

## 4. 构图与版式规格（与 V1 头像卡一致）

- 比例：**1:1**，1024×1024；半身像（约胸以上），人物**居中**。
- **头部裁切预留**：头部位于画面中心偏上，头顶至画面顶部保留约 15%–20% 净空，供前端**圆形头像裁切**。
- 微前倾读诗/捧诗稿：诗稿位于胸前偏下，不遮脸、不遮视线。
- 背景：**仅**暖米色园林景致大虚化（亭廊花木隐约成团，不可辨识具体建筑）+ **浅水菱叶**（低饱和、虚化，可作前景下缘或侧下角点缀）；背景干净素雅，无人、无文字、无器物特写。
