# OpenCode 稳定性接手说明

## 当前边界

- 不删除或清理 OpenCode 会话、草稿、Cookie、账号信息、本地数据库。
- 不从旧的“红楼社项目接续开发交接与部署要点”会话继续大规模执行。该会话历史中已经包含一次 11,523 文件的构建差异，打开/渲染它会造成明显负担；保留它作为历史证据即可。
- 新任务必须先读项目 `AGENTS.md` 的 `opencode-stability-rules`。

## 五模板卡片水印任务状态

- 用户已确认：白卡内使用浅灰褐工笔园景线描，不改页面背景，不使用文字、印章、花瓣色块或窗棂图标。
- 人物档案固定映射：是谁=A 远亭山水；经历=B 拱桥水岸；关系=C 花枝近亭；红学=D 屋檐松影；问题=E 山石荷岸。所有人物页面保持相同映射。
- 其它页面按语义使用 A-E；密集同类卡使用稳定序列，不得随机。
- 本地图片源：`public/images/garden-linework-v1.png`。现有实现尚未完成独立视觉验收，禁止部署。

## 新会话的验收方式

1. 先确认 `git status --short` 不含生成物。
2. 只验证人物详情五模块、问题网格、社区卡片的桌面和手机截图。
3. 构建输出留在已忽略目录或 `/private/tmp`，不得创建 `out-m/`、`.playwright-cli/` 等未忽略目录。
4. 报告不附大文件差异，只给改动文件、截图路径和验收结果；用户确认后才部署。
