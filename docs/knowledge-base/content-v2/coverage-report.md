## 5. 下一阶段缺口（Gap Analysis）

### 5.1 L3 深度缺口（Tier S 优先）

- **research_topics 全缺**：5 个 L3 人物档案中 `research_topics` 字段均为 0 条，而 `01-schema-v2-design.md` 要求 L3 = 14+ ResearchTopic（15 种 topic_type：生平命运线/性格研究/核心关系/诗词/判词曲文/象征意象/身份家族/经济制度/性别社会/版本差异/后四十回争议/脂批/历代红学评价/当代学术/影视改编）。**L3 评级当前是「内容广度」达成，深度专题未建**。
- 内容量：`total_content_chars` 全为 0，距标准「2–5 万字/人物」还有较大距离。

### 5.2 人物档案缺口

- **Tier B 未建档**：贾琏、赵姨娘、香菱、鸳鸯、麝月、薛姨妈、薛蟠、贾政、贾赦、邢夫人、尤氏、尤二姐、尤三姐等。
- **丫鬟层薄**：仅紫鹃、平儿、晴雯、袭人有独立档案；司棋、入画、侍书、翠缕、雪雁、莺儿等未建。
- **男性角色几乎空白**：贾琏/贾政/贾赦/贾珍/贾蓉/贾芸/柳湘莲/北静王等全缺，人物图谱性别失衡。

### 5.3 Citation / 证据缺口

- 事件级 evidence 仅 18/202（8.9%），观点条目无独立 citation 字段。
- 需要补：事件 → 原文引文（quote + 回次 + 版本）；观点 → 来源（作者/年代/出处 URL）。
- coverage.citation_coverage 声明值（0.90–0.95）与结构化字段实际填充率（~9%）不一致，需在 schema 层对齐。

### 5.4 专题与讨论缺口

- **Discussion/Post 界面数据**（§2.12）未建：缺 discussion_topics、post 模板与关联数据。
- **脂砚斋专题**：zhiyanzhai 相关内容散落在各人物档案的 disputed_version fact 中，无独立专题表。
- **影视改编比较专题**：fact_type 中 `adaptation_only` 为 0，87版/10版/电影版差异内容全缺。
- **Location 深化**：19 个地点已有骨架，但缺地点 → 事件双向索引的完整性验证。
- **章节覆盖补缺**：39 个空白回次中，第 48（香菱学诗）、第 71（鸳鸯抗婚）、第 75（中秋夜宴）等高价值回次无事件关联。

### 5.5 关联完整性

- questions.json 50 条已全部含 evidence 与 viewpoints 内嵌，质量较高；但人物档案内嵌 question 引用（122 条）与全局库（50 条）存在部分重叠，需去重并建立统一 question_id 索引。
- 关系条目中 stages 字段仅存在于重点关系（如宝黛），其余 158 条关系多数无分阶段结构。
