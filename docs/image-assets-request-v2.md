## 一、全局风格锁定（所有图片必须遵守）

- **画风**：中国古典工笔重彩 + 淡彩水墨融合（参考故宫数字展/新中式雅致风格），非写实照片、非卡通
- **时代**：清代古装（《红楼梦》背景），服饰考究、素雅
- **人物**：符合原文描写的相貌气质（下方每人有依据），面部细腻、含蓄
- **背景**：大观园园林 / 潇湘馆竹影 / 栊翠庵 / 稻香村等古典场景，虚化柔光；男性角色可用书房/厅堂/园林
- **禁止**：画面中出现任何文字、水印、边框、署名、现代元素、过重滤镜
- **同一人物**：仅生成一张，风格须与其他人物保持同一体系（同一画师感）
- **沿用 V1**：18 张已生成人物不改动；新图风格须与 V1 完全统一（同一画师感）
