# 红楼社 · 设计语言规范（雅致新中式）

> 本文档固化当前站点的设计系统，供后续开发/设计 agent 直接引用。所有令牌以 `app/globals.css` 为准，本文是它的说明。

## 一、设计基调（一句话）

**宣纸米白 + 朱砂红 + 古铜金**，宋体标题 + 无衬线正文，**线性 SVG 图标**，**禁用 emoji**。核心审美目标：雅致、克制、有版块辨识度，不「太平太素」。

### Logo（重要，避免误判）

- **主界面 Logo = `public/images/logo-universal.png`**（1617×662 横幅：红楼社书法字 + 梅花枝 + 圆形水墨插画 + HONGLOUSHE）。
- 使用位置：`components/app-sidebar.tsx`（侧边栏，`h-9 w-auto`）、`components/mobile/m-header.tsx`（移动顶栏）、`components/home-view.tsx`（首页）。
- ⚠️ `components/logo-mark.tsx`（朱红印章 SVG）与 `components/glass-nav.tsx` 是**历史死代码**（无任何页面引用），**不要再用、不要据此判断「Logo 是旧版」**。

## 三、字体

- **标题**：`--font-serif`（Noto Serif SC / Songti SC / Source Han Serif / SimSun 宋体），类名 `font-serif`。
- **正文**：`--font-sans`（Noto Sans SC / PingFang SC），类名 `font-sans`。
- **数字**：`font-mono`（关注/粉丝/积分/人数等数据）。
- **页头 eyebrow**：英文大写用 `font-sans text-[11px] tracking-[0.3em]`；中文 eyebrow 用 `font-serif text-xs tracking-[0.25em]`（**不要对中文用 font-mono**）。

## 四、图标

- 全站用 `components/icons.tsx` 的线性 SVG（`strokeWidth=1.6`，`stroke=currentColor`）。
- **禁用 emoji 和字符符号**（`♥♡✦▶＋→` 等一律换成 IconHeart/IconPlus/IconArrowRight 等 SVG）。
- 新增图标统一加到 `icons.tsx`，命名 `IconXxx`，viewBox `0 0 24 24`。
- **六大板块专属图标**（V2 已落地）：

## 五、卡片系统

- `.card-print`（`globals.css`）：白卡 + 共享园林线稿水印（5 个裁剪模板 `--identity/--timeline/--relations/--viewpoints/--questions`）+ **1px 暖色发丝边**（`inset 0 0 0 1px rgba(120,96,70,0.07)`）+ 双层阴影。
- **圆角统一两档**：主卡/内容卡 `rounded-2xl`(16px)；内层面板 `rounded-xl`(12px)；标签 `rounded-full`；印章 `rounded-[3px]`。**不要再用 `rounded-3xl`(24px) 大泡泡角**。
- **阴影**：`--shadow-card` / `--shadow-hover` 均为双层（近远两层）。
- hover 上浮统一 `-translate-y-0.5`（不要 `-translate-y-1`）。

## 六、按钮

- `.btn-primary`：朱砂渐变底（`linear-gradient(180deg,#b2403a,#a63834)`）+ 白字 + 圆角胶囊 + 按压反馈（`active:translate-y-0`）+ `focus-visible:ring-2 ring-gold/60`。
- `.btn-ghost`：描边金边按钮。
- 移动端按钮补 `active:scale-[0.98]` 按压反馈（触屏无 hover）。

## 七、动画

- **时长**：过渡 150–320ms，入场可到 420ms；**缓动用 ease-out / `cubic-bezier(0.16,1,0.3,1)`，禁用 spring 回弹、overshoot**。
- 已有 keyframe：`star-panel-in(-x)`、`sky-twinkle`、`dot-pop`、`dot-glow`、`card-pop-in/out`、`card-pop-center`、`garden-zoom-in`、`enter-blink`。
- **全站已加 `prefers-reduced-motion` 降级**（关闭无限动画）。

## 八、可访问性

- 全站 `:focus-visible` 焦点样式（`outline: 2px solid gold`）。
- 可交互图标补 `tabIndex` + 键盘事件 + `aria-*`。
- 触控目标 ≥44px；`aria-live` 播报动态内容。
