## 二、手机版是什么（先理解，避免踩坑）

- 项目是 Next.js **静态导出**。桌面版与手机版是**两次独立 build、两份独立产物**：
  - 桌面：`NEXT_PUBLIC_BASE_PATH=/honglou-yuzhou npm run build` → `out/`
  - 手机：`NEXT_PUBLIC_MOBILE=1 NEXT_PUBLIC_BASE_PATH=/honglou-yuzhou/m npm run build` → `out-mobile/`（脚本 `scripts/deploy-ecs-mobile.sh` 会 `mv out out-mobile`）
- `NEXT_PUBLIC_MOBILE=1` 触发 `lib/mobile-build.ts` 的 `IS_MOBILE_BUILD`，切换手机专属组件。
- 两版**共用同一后端** `server/api-server.js`（:4000）和**同一数据库** `server/data/hlm.db`；cookie `hlm_session` 是 `Path=/`，同域登录态共享。

## 三、路径规则（⚠️ 最容易踩的坑）

`lib/api.ts` 里两个函数分工不同：

- `sitePath(p)`：**页面跳转 / 图片等静态资源**，加 basePath（手机版含 `/m`）。
- `apiPath(p)` / `api()`：**API 请求**，自动去掉 `/m`（手机版打 `/honglou-yuzhou/api`，因为 nginx 只反代了 `/honglou-yuzhou/api/* → :4000`）。

**约定**：所有 fetch 用 `api(path)`；所有跳转/图片用 `sitePath()`；**禁止硬编码裸路径**。
